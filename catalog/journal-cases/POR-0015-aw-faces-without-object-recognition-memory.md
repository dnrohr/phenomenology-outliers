# AW: normal face recognition with selective non-face object recognition-memory failure

## Account

AW, an otherwise healthy 19-year-old with no known brain damage or broad memory impairment, was identified by online screening and then tested in the laboratory. Recognition memory was impaired within six non-face visual categories: guns, horses, scenes, tools, doors, and cars.

Seven face-recognition tests were normal. Recognition memory was also normal for houses and glasses, and recall of visual shapes was preserved. Lower-level vision, object perception, basic-level categorization, and general memory did not account for the deficit.

## Structure of the performance

- **Individual face recognition:** normal across multiple tests.
- **Within-class recognition for many objects/scenes:** impaired.
- **Object-category exceptions:** houses and glasses were spared.
- **Basic object identity:** preserved; the problem emerged when remembering individual exemplars within a class.
- **Visual shape recall:** preserved.

## Key contrasts

`face exemplar memory present` / `many object exemplar memories impaired`  
`basic category recognition present` / `within-category identity memory impaired`  
`some object classes impaired` / `houses and glasses spared`

## Why this case matters

The case shows that “object recognition” itself is too broad. Category, exemplar identity, perception, recall, and recognition memory can split—and the face/non-face boundary is not the only relevant cut.

## Source boundaries

The paper establishes behavioral selectivity but its abstract provides little phenomenological self-description. The catalog therefore avoids claiming what AW consciously saw while failing a recognition-memory test.
