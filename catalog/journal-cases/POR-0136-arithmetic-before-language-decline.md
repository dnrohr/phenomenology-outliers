# Calculation deteriorates ahead of broad language loss

## Account

A second autopsy-confirmed patient showed early, severe calculation problems with visuospatial and praxis changes while core language and memory were comparatively intact. The course demonstrates that everyday numeracy can disintegrate as a relatively selective functional system.

## Why this case matters

This report constrains the catalog's taxonomy by separating capacities that ordinary experience tends to bundle together.
