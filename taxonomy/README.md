# Evolving phenomenology taxonomy

This taxonomy begins with the earlier survey's experiments but remains explicitly open-ended. It distinguishes **content** (face, object, voice, route), **format** (image, words, spatial structure, unformulated knowing), **operation** (generate, inspect, rotate, retrieve), **state** (waking, dreaming, hypnagogic), and **metacognitive access**. Those dimensions should not be collapsed into a single vividness score.

## Baseline domains from the survey

| Domain tag | What it covers | Important separations |
|---|---|---|
| `visual-imagery` | objects, scenes, colors, detail | image vs spatial sense vs descriptive knowledge |
| `face-processing` | familiar/unfamiliar faces, identity, expression | recognition vs imagery vs configural transformation |
| `inner-speech` | spontaneous and deliberate verbal thought | words vs sound-like voice vs meaning without words |
| `auditory-imagery` | voices, environmental sounds, pitch, timbre | speech vs music; knowing vs hearing-like experience |
| `reading` | silent reading and dialogue | subvocalization vs unvoiced words vs direct meaning |
| `spatial-cognition` | routes, viewpoints, layouts, direction | visual map vs nonvisual geometry vs procedural knowing |
| `time-space` | months, years, timelines | constructed layouts vs stable automatic locations |
| `autobiographical-memory` | personally experienced past | fact knowledge vs first-person reliving |
| `conceptual-thought` | abstract/nonimagistic thinking | symbol, image, word, felt relation, unformulated knowing |
| `agency-intention` | deciding and initiating action | narrated decision vs urge vs action without prior content |
| `memory-search` | retrieval dynamics | active search vs cue-triggered arrival vs feeling of knowing |
| `metacognition` | certainty, error, familiarity | experience vs inference; access vs performance |
| `interoception` | hunger, heartbeat, breath, visceral state | localized sensation vs diffuse affect vs conceptual knowledge |
| `bodily-awareness` | proprioception, touch, pain, ownership | sensory intensity vs unpleasantness vs ownership vs control |
| `unstructured-consciousness` | rest, silence, absorption | absence of reportable content vs absence of consciousness |

## Extensions forced by the present corpus

| Tag | Added because |
|---|---|
| `dreaming` | vivid involuntary dream vision can coexist with absent waking voluntary imagery |
| `synesthesia` | one modality or concept can automatically generate another conscious concurrent |
| `orthographic-imagery` | speech may appear as written words with font, case, position, and crowding behavior |
| `motion-perception` | color, form, and motion can dissociate within ordinary vision |
| `affective-valuation` | sensory detection can separate from unpleasantness, avoidance, or fear |
| `emotion` | a specific emotion can be selectively reduced while other emotions remain available |
| `color-perception` | wavelength discrimination, color knowledge, perceptual color, and imagined color can separate |
| `object-recognition` | perception, identity access, copying, drawing, and action guidance can dissociate |
| `proprioception` | motor control may depend on conscious visual substitution when body-position feedback is absent |
| `hypnagogia` | imagery near sleep may be photorealistic, involuntary, and distinct from both waking imagery and dreams |
| `sleep` | paralysis, cataplexy, explosive sounds, and hallucinations can dissociate awareness from muscle control and external stimulation |
| `smell` / `taste` | chemical senses can be absent, distorted, or positively generated without a stimulus |
| `ownership` | a limb can be sensed and controlled yet not feel owned, or an additional limb can feel embodied |
| `navigation` | route following, landmark familiarity, cognitive maps, and mental viewpoint can fail separately |
| `speech` / `language` | speech content, prosody, word recognition, and environmental-sound recognition can dissociate |
| `self` | experienced self-location can move outside, behind, or into an indeterminate relation with the body |
| `math` | quantity, exact facts, approximation, operations, calendars, and numerical semantics can dissociate |
| `scene-representation` | objects and details may be available without a coherent, extended spatial setting |
| `touch` / `pain` | detection, localization, intensity, unpleasantness, and defensive action can separate |
| `voice-processing` | speech content can remain intelligible when speaker identity or vocal affect is unavailable |
